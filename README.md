# 🧠 AI Language Learning Assistant

An interactive Streamlit app that helps users translate phrases, explore grammar, and drill vocabulary. Built using OpenAI's GPT API for language processing.

## ✨ Features

- 🔤 Translate user-entered text using GPT
- 📚 Grammar explanation generation
- 🎙️ Audio generation for translated sentence + vocab words
- 🌍 Multilingual: English, Japanese, Polish
- 🔐 Secure `.env` API key handling (or Streamlit Secrets)
